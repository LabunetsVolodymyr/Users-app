# Лабораторна робота №3: Основи роботи з компонентами, шаблони, директиви Vue.js

Цей проєкт реалізовано на базі **Vue 3 (Composition API)** з використанням **TypeScript** та **Vite**.

## Реалізований функціонал:
- Створення Single File Components (`App.vue`, `Users.vue`, `UserCard.vue`) з повною TypeScript-типізацією.
- Відображення списку з 10 користувачів на основі розширеного JSON-датасету.
- Картка користувача відповідно до наданого макета (аватарки, контактні дані, адреса, бейджі хобі).
- Директива `v-if` для відображення віку лише якщо він більше 18 років.
- Директива `v-for` для виведення списку хобі та списку карток.
- Директива `v-show` для приховування/розгортання блоку «About me».
- Об'єктний синтаксис `:class` для колірного маркування карток залежно від віку (minor, young, adult, senior).
- Тулбар фільтрації (за статтю, віком 18+) та сортування (за ім'ям і віком у двох напрямках).
- Кнопка повного скидання параметрів до початкового стану.
- Перевірка та повідомлення для порожнього списку.
- Скріншоти пройденого офіційного туторіалу Vue розміщені у папці `public/tutorial/`.
